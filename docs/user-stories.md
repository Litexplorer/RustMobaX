# 用户故事

本文是需求主干。故事按 **Epic** 分组，编号规则 `US-<Epic 编号><序号>`。

## 阅读约定

**角色**

| 代号 | 角色 | 典型诉求 |
| --- | --- | --- |
| 运维 | SRE / 系统运维 | 一人管几十台机器，要素是效率与稳 |
| 开发 | 后端 / 全栈开发 | 边写边连，痛点在传文件 |
| 网工 | 网络 / 嵌入式工程师 | 串口、Telnet、链路排查 |
| 科研 | 数据 / 科研人员 | 服务器上跑图形程序 |
| 新手 | 学生 / 临时使用者 | 免配置、少概念 |

**优先级**：P0 首版闭环 · P1 第二阶段 · P2 长期。

**故事模板**：`作为 <角色>，我希望 <能力>，以便 <价值>`，后接验收标准（可测的行为断言）。

## E1 会话管理

### US-101 新建并保存一个会话 · P0
作为**运维**，我希望新建会话时把主机、端口、用户名、认证方式一次填完并保存，以便下次一键连上而不用翻笔记。
- 必填校验：名称与主机缺失时不允许保存，并就近提示；用户名留空表示沿用远端登录名
- 认证方式由是否指定私钥推导：填了私钥路径即为私钥认证，否则用密码
- 高级项（X11 转发、登录后执行命令、私钥路径）随会话保存，重开后仍在
- 保存后立即出现在会话列表，且能直接双击连接
- 会话数据落 SQLite，关闭应用重开仍在

### US-102 按分组组织会话 · P0
作为**运维**，我希望把会话放进分组（如"生产/预发/数据库"）并支持嵌套，以便机器多了以后仍能快速定位。
- 支持两级以上嵌套分组与拖拽移动
- 分组可折叠，折叠状态持久化
- 删除分组时提示"会话将移至未分组"，不静默删除会话

### US-103 搜索会话 · P0
作为**运维**，我希望在会话列表里输入关键字（主机名 / IP / 分组 / 标签）即时过滤，以便在 100+ 会话中 2 秒内找到目标。
- 输入即过滤，无提交动作
- 关键字匹配不区分大小写，命中部分高亮
- 无结果时给出空态文案，而不是空白列表

### US-104 一键复制并派生会话 · P1
作为**运维**，我希望复制已有会话再改主机名，以便批量录入同构机器。
- 复制后名称自动加后缀，且不覆盖原有会话
- 复制包含除凭据引用外的全部字段

### US-105 导入 MobaXterm 会话 · P0
作为**新手**，我希望导入已有的 `.mxtsessions` 文件，以便迁移时不用重录几十个会话。
- 能解析 INI 风格会话段，导入 SSH / SFTP / 本地终端三类
- 无法识别的字段忽略并在导入结果里列出条数与原因
- 导入前预览将要新增的会话数量，允许取消
- 导入失败不破坏已有会话库

### US-106 导出会话（含脱敏） · P1
作为**运维**，我希望把会话导出为可分享的文件并选择是否包含密码，以便交接给同事。
- 默认导出不含任何密码/私钥内容
- 勾选"包含凭据"时二次确认，并提示风险
- 导出的文件可被本应用重新导入，往返字段一致

## E2 远程终端（SSH）

### US-201 建立 SSH 会话并打开终端 · P0
作为**运维**，我希望填完信息点"连接"就得到一个可交互终端，以便不依赖命令行拼参数。
- 支持密码、私钥（含带 passphrase）、SSH Agent 三种认证
- 首次连接未知主机弹出指纹确认；拒绝时断开且不写入 known_hosts
- 连接失败按 DNS / TCP / 握手 / 认证 / 超时分类给出可读原因
- 内网环境从点击到可输入 ≤ 3 秒

### US-202 终端正确渲染 · P0
作为**开发**，我希望终端能正确显示颜色、光标、宽字符和 TUI 程序，以便 vim / htop / tmux 都能正常用。
- TrueColor 与 256 色正确显示
- 中文字符与 emoji 不出现错位、不吞字
- 打开 `vim`、`htop`、`tmux` 无花屏；窗口 resize 后立即重排
- 鼠标滚轮在 alt-screen 下交给远端程序处理

### US-203 多标签终端 · P0
作为**运维**，我希望同时开多个标签并快速切换，以便并排处理多台机器。
- 标签可拖动排序、可中键关闭
- 未读输出在后台标签上有提示标记
- 关闭有活动进程的标签时二次确认
- 标签数量无硬上限

### US-204 分屏 · P0
作为**开发**，我希望把一个窗口水平或垂直切成多块，以便同时看日志和敲命令。
- 支持横向 / 纵向切分，可嵌套
- 分割条可拖拽调整比例
- 分屏布局在应用重启后恢复
- 关闭某块后剩余区域自动占满

### US-205 终端内搜索与回滚 · P0
作为**运维**，我希望在终端输出里搜索关键字并回看历史，以便快速定位报错。
- 支持上下查找、高亮全部命中、显示命中序号
- 回滚缓冲 ≥ 10000 行，且在设置里可调
- 清屏后回滚内容可清空

### US-206 粘贴保护与多行粘贴 · P0
作为**运维**，我希望粘贴多行命令时有确认，以便不会误在生产机执行一大段脚本。
- 多行粘贴弹出摘要确认，可看到前几行
- 含 `rm -rf`、`dd`、`mkfs` 等危险模式时高亮警示
- 支持括号粘贴模式，远端未开启时自动降级

### US-207 断线提示与重连 · P1
作为**运维**，我希望网络抖动断开后能看到明确提示并一键重连，以便不用重建整个会话。
- 断开时终端保留已输出内容并显示横幅
- 一键重连复用原会话参数与凭据
- 重连成功后可选择是否执行原 `pre-command`

### US-208 会话日志记录 · P1
作为**运维**，我希望把终端输出保存成带时间戳的日志文件，以便事后复盘。
- 可按会话开启，选择纯文本或带 ANSI 转义两种格式
- 日志路径模板支持 `{host}` `{date}` 变量
- 关闭会话时自动 flush 并落盘，进程崩溃不丢已写内容

## E3 本地与串口终端

### US-301 打开本地 Shell 会话 · P0
作为**开发**，我希望开一个本地终端标签，以便不用另开一个终端窗口。
- Windows 下可选 PowerShell / CMD / WSL 发行版
- mac / Linux 下使用 `$SHELL`
- 工作目录可指定，未指定时用用户主目录
- 与远程终端共享同一套渲染与快捷键

### US-302 串口终端 · P1
作为**网工**，我希望直接连串口并选择波特率，以便调试交换机和开发板。
- 可选端口、波特率、数据位、停止位、校验位、流控
- 插入/拔出设备后列表可刷新
- 发送支持 CR / LF / CRLF 结尾切换
- 断开时提示，不静默失败

### US-303 Telnet 会话 · P1
作为**网工**，我希望用 Telnet 连老设备，以便不额外装工具。
- 支持基本选项协商（ECHO / SGA / TTYPE）
- 窗口尺寸变化时发送 NAWS 协商
- 明确标注"明文协议"警告

### US-304 WSL 发行版发现 · P1
作为**开发**，我希望能列出已安装的 WSL 发行版并直接进入，以便不用记 `wsl -d` 参数。
- 自动枚举发行版并显示默认标记
- 无法枚举时降级为手填发行版名

## E4 SFTP 文件工作流

### US-401 打开 SFTP 侧栏 · P0
作为**开发**，我希望 SSH 会话旁边直接出现文件面板，以便不用再开一个 FTP 客户端。
- 与会话共享同一条 SSH 连接，不额外建连
- 面板可折叠、可调整宽度
- 打开时定位到远端登录目录

### US-402 跟随终端切换目录 · P0
作为**开发**，我希望在终端里 `cd` 之后文件面板自动跟随，以便不用两边手工对齐路径。
- 终端 cwd 变化后 1 秒内面板同步
- 同步时保留用户在面板里的滚动位置以外的状态（选中项按路径匹配）
- 远端 shell 不上报 cwd 时，回退为手动刷新，并在 UI 上说明

### US-403 上传与下载 · P0
作为**开发**，我希望能拖拽文件完成上传下载，以便不用记命令。
- 支持拖拽到面板上传、拖拽到系统文件管理器下载
- 传输中显示进度、速度、剩余时间
- 大文件分块传输，可取消，取消后清理临时文件
- 同名文件冲突时询问覆盖 / 跳过 / 重命名

### US-404 文件基本操作 · P0
作为**开发**，我希望在面板里新建目录、重命名、删除、改权限，以便日常维护不切工具。
- 所有破坏性操作需确认，删除默认走二次确认
- 权限修改提供八进制输入与常见预设
- 操作失败给出远端返回的错误信息原文

### US-405 内置编辑器 · P0
作为**开发**，我希望双击文本文件就地编辑并保存回远端，以便改配置不用 vim。
- 只对文本文件启用编辑，二进制文件给出提示
- 保存前检测远端 mtime 是否被他人改动，冲突时提示
- 支持语法高亮与换行符（LF/CRLF）识别

### US-406 传输队列 · P1
作为**开发**，我希望看到所有传输任务并调整并发，以便大批量传文件时可控。
- 队列展示排队 / 进行中 / 完成 / 失败分组
- 并发数可配置，默认 2
- 失败任务可单条重试、可一键重试全部

### US-407 断点续传 · P1
作为**开发**，我希望中断的大文件能续传，以便不用从头再来。
- 以远端文件大小 + 本地大小比对决定续传起点
- 远端不支持追加写时回退为整文件重传并提示

### US-408 目录同步 · P2
作为**运维**，我希望对比本地与远端目录差异并同步，以便批量部署文件。
- 差异判定基于相对路径 + 大小 + mtime
- 同步前给出"仅上传 / 仅下载 / 冲突"三类清单
- 执行前需要确认，执行后输出成功与失败明细

## E5 端口转发与隧道

### US-501 本地端口转发 · P0
作为**开发**，我希望把远端数据库端口映射到本地，以便本地工具直连。
- 可配置本地监听地址/端口与目标主机/端口
- 本地端口被占用时明确报错并建议改端口
- 隧道建立后在 UI 显示"运行中"状态与连接计数

### US-502 远程端口转发 · P0
作为**运维**，我希望把本地服务暴露到远端，以便远端机器访问我的环境。
- 支持指定远端监听地址与端口
- 远端拒绝监听（`tcpip-forward` 失败）时给出原因
- 关闭会话时自动撤销远端监听

### US-503 动态 SOCKS5 转发 · P0
作为**运开**，我希望开一个 SOCKS5 代理，以便浏览器和命令行走跳板机出网。
- 支持 SOCKS5 CONNECT，含用户名密码认证模式
- 不支持的命令（BIND/UDP ASSOCIATE）返回标准错误码
- 代理端口与状态在 UI 可见，可一键停止

### US-504 隧道面板与自动重连 · P1
作为**运维**，我希望隧道断开后自动重连并留痕，以便长跑的隧道不用盯着。
- 断开后指数退避重连，最长间隔可配置
- 面板展示每条隧道的累计连接数、最后错误、最近重连时间
- 可手动禁用某条隧道的自动重连

### US-505 跳板机（ProxyJump） · P0
作为**运维**，我希望通过跳板机连目标机，以便不在每台机器上装公网入口。
- 会话配置里可选择"经由会话"指定跳板
- 支持单跳；多跳列为 P1
- 跳板断开时目标会话给出关联提示
- 认证信息分别配置，不共享错误凭据

## E6 凭据与安全

### US-601 设置主密码 · P0
作为**运维**，我希望设置一个主密码来保护所有凭据，以便电脑被拿到时密码不裸奔。
- 首次启用时强制设置，强度不足给出提示但不强制拦截
- 锁屏/超时可自动上锁，超时时长可配置
- 主密码遗忘时只能重置并清空凭据库，明确告知不可恢复

### US-602 凭据加密存储 · P0
作为**安全敏感用户**，我希望密码与私钥以加密形式落盘，以便磁盘被拷走也读不出明文。
- 使用 Argon2id 派生密钥 + AES-256-GCM 加密
- 加密后文件里不出现任何明文主机密码片段
- 明文只在解锁期的内存中存在，锁定后立即清除

### US-603 主机指纹校验 · P0
作为**运维**，我希望校验 SSH 主机指纹，以便避免中间人。
- 首次连接展示指纹（含 MD5 与 SHA256 两种格式）并请求确认
- 指纹变化时阻断连接并强烈警示，需手动删除旧记录才能继续
- known_hosts 支持导入导出

### US-604 二次验证登录 · P0
作为**运维**，我希望连接受 OTP 保护的机器时能输入验证码，以便完成键盘交互式认证。
- 认证过程中按远端提示弹出输入框，支持多轮
- 验证码输入框屏蔽回显并支持粘贴
- 认证被拒后保留会话配置供重试

### US-605 系统钥匙串集成 · P1
作为**开发**，我希望复用系统已保存的凭据，以便少输一次密码。
- 支持 macOS Keychain、Windows Credential Manager、Linux Secret Service
- 钥匙串不可用时自动降级到内置加密库，并给出提示

### US-606 凭据访问可见 · P2
作为**安全审计者**，我希望看到凭据的使用记录，以便排查异常访问。
- 记录时间、会话、凭据标识（不记录明文）
- 记录可导出为 CSV
- 记录条数上限可配置，超出滚动清理

## E7 网络工具箱

### US-701 连通性检测 · P1
作为**运维**，我希望在应用内对某主机 ping，以便判断是网络还是服务的问题。
- 连续 ping 显示逐包 RTT 与丢包率
- 支持指定次数与超时
- 无 ICMP 权限时自动降级为 TCP 探测并说明

### US-702 路由追踪 · P1
作为**网工**，我希望做 traceroute 看链路在哪一跳断了，以便定位运营商问题。
- 逐跳显示 IP、RTT、超时标记
- 可设置最大跳数与每跳探测次数
- 结果可导出文本

### US-703 DNS 查询 · P1
作为**运维**，我希望查 A/AAAA/CNAME/MX/TXT 记录，以便确认解析是否正确。
- 支持指定 DNS 服务器
- 显示 TTL 与响应耗时
- 解析失败区分 NXDOMAIN / SERVFAIL / 超时

### US-704 whois 与端口探测 · P1
作为**网工**，我希望查 IP 归属并探测端口开放情况，以便快速判断可达性。
- whois 直连 43 端口并原样展示，支持被拒绝时的提示
- 端口探测支持端口列表与并发上限，结果分"开放/关闭/过滤"
- 探测需用户显式触发，默认不对公网批量执行

## E8 多执行与宏

## E9 图形转发（X11）

### US-901 一键开启 X11 转发 · P1
作为**科研**，我希望勾选 X11 转发后远程 GUI 程序能弹到我桌面，以便不用手工配环境变量。
- 勾选后自动设置 `DISPLAY` 与 `xauth`
- 远程程序窗口能正常出现并可交互
- 本地没有可用 X server 时给出可操作的引导，而不是静默失败

### US-902 复用系统 X server · P1
作为**科研**，我希望在 Linux/mac 上直接复用系统的 X server，以便不必装额外软件。
- Linux 下连接当前 `$DISPLAY`
- macOS 下检测 XQuartz 是否运行并提示启动
- Windows 下检测内置/外挂 X server 状态并给出安装引导

### US-903 内嵌 X server · P2
作为**新手**，我希望 Windows 上开箱就能显示远程 GUI，以便不折腾 X server。

## E12 多协议终端接入

本 Epic 是对已有 US-301 / US-302 / US-303 / US-304 / US-1101 / US-1102 / US-1103 的细化与补充，已有故事原文保留不动；本组负责把它们拆成可测的验收细节，并补上协议适配层这一前置抽象。

### US-1201 协议适配层抽象 · P1
作为**开发**，我希望终端泵只依赖一个统一的传输接口，以便新增一种协议时只写一个实现，不用改泵和前端渲染。
- 定义 `TerminalTransport` trait，方法固定为 `open(TermSize)` / `write(&[u8])` / `resize(TermSize)` / `close()`；`ssh`、`local-pty`、`telnet`、`serial` 各提供一个实现，`terminal/pump.rs` 内不出现任何协议分支（该文件中 `Protocol::` 匹配数为 0）
- 新增协议只需新增一个 `transport/<name>.rs` 与 `Protocol` 枚举的一个值，并同步 `as_str` / `parse` 两张表；存量 `ssh` / `sftp` / `local` 记录反序列化不报错，旧会话仍可打开
- 所有协议的字节流型会话共用同一个 `TerminalRegistry`，按 `session_id` 路由；不存在为某协议单开的第二套 registry 或第二套标签容器
- 前端"按协议启动会话"的分发收敛为单一入口（当前散落在 `src/App.tsx` / `SessionTree.tsx` / `SessionDialog.tsx` 的 `session.protocol === "..."` 判断合并为一个映射表或工厂），新增一种协议时前端改动点 ≤ 1 处
- 图形协议（RDP / VNC）只要求满足 trait 的连接生命周期语义，渲染路径独立，不并入 xterm 终端渲染

### US-1202 Telnet 会话 · P1
作为**运维**，我希望用 Telnet 直接连老设备，以便不用额外装一个终端工具。
- 新建会话时 `protocol` 可选 `telnet`，端口留空时默认 23；保存后出现在会话树，双击即可连接
- Telnet 是明文协议：连接前的确认提示与终端标签头都标注"明文传输，凭据与输出不加密"，且该提示不提供"不再提醒"的永久关闭项
- 会话模型复用现有 `session` 表的 `host` / `port` / `username` 字段，不新增表、不新增列；`requires_host` 对 `telnet` 返回 true，用户名允许为空
- 连接后得到可交互终端：输入能送达、远端回显正常，标签、分屏、快捷键与其他协议共用同一套实现
- 终端内搜索与回滚（US-205 的能力）在 telnet 会话中可用；会话日志（US-208）可按会话开启
- 连接失败按 DNS / TCP / 超时分类给出可读原因，沿用 US-201 的错误分类口径，不新造一套错误码

### US-1203 Telnet 协商与终端类型 · P1
作为**网工**，我希望客户端正确处理 Telnet 选项协商，以便登录交换机后不出现满屏乱码或无法输入。
- 实现最小协商子集：WILL / WONT / DO / DONT 四类命令，以及 ECHO、SGA、TTYPE（24）、NAWS（31）四个选项；其余选项一律以 DONT / WONT 拒绝，不透传给渲染层
- 收到 TTYPE 请求时回送 `TERM` 值，默认 `xterm-256color`，可在会话高级项覆盖；双方互相请求同一选项时协商在 3 轮内收敛并停止发送
- 窗口尺寸变化后 200ms 内发出 NAWS 子协商（宽高为 16 位大端两字段）；协商完成后立即上报一次初始尺寸，使远端 `vim` / `top` 排版正确
- 回显不叠加：远端声明 WILL ECHO 时关闭本地回显，未声明时开启本地回显，同一会话内不会出现双字符
- 字符集可配（默认 UTF-8，可选 GBK）：非 UTF-8 时按所选编码解码后再送渲染；无法解码的字节显示为替代符，不丢弃整行输出
- 按 RFC 854 处理转义序列：`IAC IAC` 解析为字面 0xFF，截断或非法的 IAC 序列被丢弃后继续会话，不断连
- 协议无关复用：协商层只做字节预处理，输出仍走统一泵与 xterm 渲染；新增的只有协商状态机本身

### US-1204 串口连接 · P1
作为**网工**，我希望直接连本机串口并把它保存成会话，以便调试交换机和开发板时不用每次重选端口。
- 新建串口会话时端口为下拉枚举，覆盖 Linux `/dev/ttyUSB*` `/dev/ttyACM*`、mac `/dev/cu.*`、Windows `COM*`，并显示设备描述；USB 转串口设备能被枚举出来
- 串口没有网络语义：表单不展示主机/端口输入，落库时 `host` / `port` 为空，`requires_host` 对 `serial` 返回 false
- 会话可命名保存并在会话树中复用，双击以原参数重连；不新增存储，复用现有会话树与 SQLite 会话表
- 连接状态在标签与状态栏可见（已连接 / 已断开 / 打开失败），不存在"界面显示已连接但没有数据"的静默态
- 端口被占用、权限不足（如 Linux 未加入 `dialout` 组）时给出可读错误并指明所需操作，不只回 errno 数字
- 发送结尾支持 CR / LF / CRLF 切换，切换对下一次发送立即生效

### US-1205 串口参数配置 · P1
作为**网工**，我希望配置波特率、数据位、停止位、校验与流控，以便匹配不同设备的串口参数。
- 参数项齐备：波特率（含 9600 / 19200 / 38400 / 57600 / 115200 及自定义数值）、数据位 5–8、停止位 1 / 1.5 / 2、校验 None / Even / Odd / Mark / Space、流控 None / RTS-CTS / XON-XOFF
- 默认值为 9600 8N1、无流控；新建会话不填任何参数直接保存，落库值与默认值一致
- 参数写入会话的 `extra_json`（协议私有配置），不新增数据库列；重启应用后参数仍在，重连即按原参数打开
- 运行中修改参数不即时生效，UI 明确提示"需重新打开端口"，修改后立即可从会话详情看到新值
- 驱动不支持的波特率或字段取值在打开端口时被拦截，提示指明是哪一项不合法及可接受范围，而不是笼统的"打开失败"
- 设备被拔出时，已连接会话在 2 秒内显示"设备已断开"，保留已输出内容，不崩溃、不静默卡死

### US-1206 WSL 发行版会话 · P1
作为**开发**，我希望列出已安装的 WSL 发行版并直接以指定发行版开终端，以便不离开应用就进入 Linux 环境。
- 通过 `wsl.exe -l -v`（或等价接口）枚举发行版，展示名称、运行状态与默认标记；结果在当前运行期内缓存，并提供手动刷新
- 新建本地 Shell 会话时可指定发行版，连接时以该发行版启动（等价 `wsl.exe -d <发行版>`），起始目录为 Windows 侧当前目录映射后的路径
- 提供"默认发行版"选项，用户不显式选择时使用默认；默认标记以系统返回值决定，不硬编码发行版名
- 仅 Windows 可用：非 Windows 平台不渲染 WSL 选项，或渲染为禁用并给出"此功能仅在 Windows 下可用"的说明
- WSL 未启用或 `wsl.exe` 不可用时给出引导文案（启用 WSL、安装发行版的具体命令或链接），不显示空下拉或直接抛错
- 枚举失败（如输出编码异常）时降级为手填发行版名，手填值同样能打开终端；复用现有本地 Shell 会话路径与渲染，不新增会话类型

### US-1207 RDP 远程桌面 · P2
作为**运维**，我希望在应用里直接连 Windows 机器的桌面，以便不切换到别的客户端。
- 新建会话支持 `protocol = rdp`，端口留空默认 3389；主机、用户名、域、分辨率与缩放比例随会话保存
- 凭据走现有凭据库（`credential_ref`），`session` 表与会话日志中不出现明文密码；凭据库未解锁时先要求解锁再连接
- 分辨率支持"跟随窗口"与固定档位，缩放可选 100% / 125% / 150% 并与会话一起保存；可进入全屏并可用约定快捷键退回窗口（快捷键列入 US-1002 的键位表）
- 剪贴板文本双向可用（本地→远端、远端→本地）；任一方向不可用时明确提示该方向不可用，不静默失败
- 键盘映射的最小可用集写入验收：字母数字、Ctrl / Alt / Shift / Win 修饰键、方向键、Tab、Enter、Backspace、Esc；不在最小集内的按键缺失不算阻断缺陷
- 图形渲染与 xterm 是两套路径：画面在独立视图渲染，不复用终端字节泵，因此终端内搜索、回滚、日志不适用于 RDP，UI 不展示这些入口
- 连接失败按 DNS / TCP / TLS / 认证 / 超时分类给出可读原因，口径与 US-201 一致

### US-1208 VNC 远程桌面 · P2
作为**运维**，我希望连 VNC 服务管理没有 RDP 的设备，以便把远程操作收在一个客户端里。
- 新建会话支持 `protocol = vnc`，端口留空默认 5900（显示号 n 对应 5900+n）；密码走凭据库，不明文落库
- 写明 VNC 协议限制：密码认证只使用前 8 个字符，输入超过 8 字符时提示"VNC 仅使用前 8 个字符"，允许继续保存，不静默截断
- 支持只读模式：开启后本地键鼠输入不发送到远端，状态在标签上可见且重启后按会话配置恢复
- 支持缩放适配（等比缩放到窗口）与 1:1 原始尺寸切换，窗口 resize 后画面等比变化、不拉伸变形
- 服务器使用不支持的 RFB 安全类型或编码时，给出指明具体项的错误（如"服务器要求不支持的编码 Tight"），不显示黑屏或空窗口
- 渲染独立于 xterm 终端，终端内搜索 / 日志 / 回滚不适用于 VNC，UI 不提供这些入口

### US-1209 远程桌面降级到系统客户端 · P2
作为**运维**，我希望在自研桌面实现不可用时用系统客户端打开同一会话，以便仍然能完成工作。
- 按协议检测系统客户端：Windows 查 `mstsc`，mac / Linux 查 `xfreerdp` 或 `remmina`，VNC 查 `vncviewer` 或 `remmina`；检测不到即判定为不存在，不做乐观假设
- 会话右键菜单提供"用系统客户端打开"，存在时一键调起，并把主机、端口、用户名、域（VNC 为显示号）作为参数传入
- 凭据默认不进入命令行；用户显式勾选"传递密码"时需二次确认，并在提示中写明密码会出现在进程参数里、可被本机其他用户看到
- 客户端不存在时给出针对当前平台的安装引导（包名或下载链接），并提供"复制连接串"作为兜底手段
- 调起失败（进程启动异常或客户端立即以非 0 退出）时回读 stderr 摘要并展示，不只报"打开失败"
- 复用现有会话字段与凭据库，不新增存储；降级打开不占用应用内会话标签，也不在 `TerminalRegistry` 中留下悬挂条目
